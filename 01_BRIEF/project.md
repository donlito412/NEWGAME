# PROJECT NAME

Lil Artie: Roads of Amani

# CURRENT STATE

An existing playable Three.js open-world vertical slice is being upgraded in place. The application uses Next.js, React, Three.js, Vinext, Vite, and Cloudflare-compatible build tooling. The game includes a procedural stylized landscape, Lil Artie as the playable African American teenage protagonist with dreadlocks, third-person movement, sprinting, jumping, stamina, health, human enemies, melee combat, a traveler rescue situation, a quest HUD, a minimap, desktop controls, and touch controls. Downloaded village, nature, human character, equipment, mountain, and GitHub character assets are now connected to the scene.

Working source remains in its existing locations so the application is not broken:

- `/app/`
- `/public/`
- `/docs/`
- `/tests/`
- `/worker/`
- `/db/`

# GOAL

Develop Lil Artie: Roads of Amani into a stylized open-world 3D adventure inspired by the exploration freedom, discovery, traversal, and environmental storytelling of The Legend of Zelda: Breath of the Wild, without monsters. Threats and challenges must use believable human enemies and realistic situations. All incorporated third-party assets must be free or already owned by the project owner and must have recorded usage rights.

# NEXT MILESTONE

Full code rebuild (owner-directed, 2026-07-24): rewrite /app/game/ from scratch with skeletal animation, real collision, a deliberate village layout, animated human NPCs and enemies, a working minimap, and a quest chain — reusing all owned assets plus newly sourced free assets with recorded licenses. No placeholders. No blocky (Minecraft/Roblox) aesthetic. Tasks TASK_100 through TASK_105.
